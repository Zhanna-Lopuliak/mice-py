# Legacy simulation results

The files in `Data/` come from an earlier simulation study of mice-py. The code
that produced them is not in this repository or its history, so they cannot be
reproduced or checked. They predate the fixes of version 0.2.0 (among others the
corrected coefficient draw, the CART and random forest changes and the new
defaults), so they do not describe the current library.

- `Data/Inputs/`: the input datasets of that study.
- `Data/Results/`: its summary tables.

They are kept for reference only. The current simulation study, which compares
mice-py with R mice on datasets with known truth, is in the parent folder
(`simulations/README.md`).
